# 项目功能清单

> 基于 `session-maintenance-system` 前端代码和后端 API 整理  
> 生成日期：2026-07-01

---

## 导航结构（侧边栏 9 个页面入口）

| 页面 | 路由 | 描述 |
|------|------|------|
| 总览 | `/dashboard` | 系统状态总览、统计卡片、快捷动作 |
| 维护任务 | `/tasks` | 维护任务 CRUD、启停、执行、查看详情 |
| 健康检测 | `/checks` | 健康检测规则管理、手动/批量执行 |
| Profile 目录 | `/profiles` | 浏览器 Profile 注册、锁定、复检 |
| 脚本库 | `/scripts` | 脚本上传、详情查看、启停切换 |
| 人工修复 | `/repairs` | 工单处理流程：打开浏览器→复检→关闭 |
| 环境自检 | `/environment` | Windows 节点环境检查 |
| 部署配置 | `/deploy` | 部署信息展示（只读） |
| 运行日志 | `/logs` | 运行记录筛选与查看 |

---

## 一、总览页 (`/dashboard`)

### 统计卡片（4 个只读）
- 维护任务总数
- Profile 目录数
- 健康检测数
- 待人工修复数

### 按钮

| 按钮 | 动作 |
|------|------|
| 刷新总览 | 重新加载 Dashboard 数据 |

### 全局快捷动作栏 (QuickActionBar)

| 按钮 | 动作 |
|------|------|
| 执行环境自检 | 跳转 `/environment?autorun=1`，自动执行环境检测 |
| 执行全部健康检测 | 跳转 `/checks?runAll=1`，自动批量执行健康检测 |
| 新增维护任务 | 跳转 `/tasks?create=1`，打开创建任务弹窗 |
| 新增健康检测 | 跳转 `/checks?create=1`，打开创建检测弹窗 |
| 上传脚本 | 跳转 `/scripts?upload=1`，打开脚本上传弹窗 |

### 内容区块
- 当前主流程说明（3 步文字流程）
- 最近日志列表
- 最近健康检测表格

---

## 二、维护任务页 (`/tasks`)

### 统计卡片（3 个只读）
- 任务总数
- 有效任务
- 风险任务

### 筛选器

| 控件 | 类型 | 说明 |
|------|------|------|
| 任务状态 | 下拉框 | INIT / VALID / EXPIRED / REFRESHING / RISK / DISABLED |
| 关键字搜索 | 输入框 | 搜索任务名、编码、渠道、手机号、Profile、脚本 |

### 按钮

| 按钮 | 位置 | 动作 |
|------|------|------|
| 新增维护任务 | 顶部 | 打开 TaskFormDialog（创建模式） |
| 详情 | 行操作 | 打开 TaskDetailDialog |
| 编辑 | 行操作 | 打开 TaskFormDialog（编辑模式） |
| 执行脚本 | 行操作 | 调用后端手动执行任务 |
| 打开修复浏览器 | 行操作 | 查找关联工单 → 在桌面打开浏览器 |
| 停用 / 启用 | 行操作 | 切换任务 enabled 状态 |

### TaskFormDialog（新增/编辑）

**字段**：
- 任务名称（必填）
- 渠道（必填）
- 手机号（必填）
- 账号别名
- 关联 DNS（逗号或换行分隔）
- 维护脚本（下拉，仅显示 MAINTAIN 类型且启用的脚本）
- Profile（下拉）
- 运行频率类型
- 运行频率值
- 脚本配置 JSON

**按钮**：
- 取消
- 保存任务 / 保存修改

### TaskDetailDialog

**展示内容**：
- 基础信息：任务编码、名称、渠道/手机号、账号别名、状态、运行频率
- 绑定信息：Profile Key、相对路径、绝对路径、脚本信息
- DNS 与最近运行：DNS 列表、最近运行状态/时间、产物目录、错误信息
- 绑定健康检测列表
- 脚本配置 JSON

**按钮**：关闭 / 执行脚本

---

## 三、健康检测页 (`/checks`)

### 统计卡片（3 个只读）
- 检测总数
- 通过
- 失败

### 筛选器

| 控件 | 类型 | 说明 |
|------|------|------|
| 检测状态 | 下拉框 | PENDING / PASS / FAIL / DISABLED |
| 关键字搜索 | 输入框 | 搜索检测名、店铺、手机号、DNS、任务 |

### 按钮

| 按钮 | 位置 | 动作 |
|------|------|------|
| 执行全部健康检测 | 顶部 | 批量执行所有启用的健康检测 |
| 新增健康检测 | 顶部 | 打开 HealthCheckFormDialog |
| 编辑 | 行操作 | 打开 HealthCheckFormDialog 编辑 |
| 执行检测 | 行操作 | 手动执行单条检测 |
| 停用 / 启用 | 行操作 | 切换检测 enabled 状态 |

### HealthCheckFormDialog

**字段**：
- 检测名称（必填）
- 旧 cookie 表
- 渠道（必填）
- 店铺名称（必填）
- 手机号（必填）
- DNS（必填）
- 请求方法
- 检测 URL（必填）
- 失败触发任务（下拉，可选）
- 请求头 JSON
- 请求体 JSON
- 成功规则 JSON
- 失败规则 JSON

**按钮**：取消 / 保存检测（或 保存修改）

---

## 四、Profile 目录页 (`/profiles`)

### 统计卡片（3 个只读）
- Profile 总数
- 锁定中
- 风险 / 损坏

### 按钮

| 按钮 | 位置 | 动作 |
|------|------|------|
| 登记 Profile | 顶部 | 打开 ProfileFormDialog |
| 复检 | 行操作 | 调用后端校验 Profile 状态 |
| 打开修复浏览器 | 行操作 | 查找关联工单，在桌面打开修复浏览器 |
| 锁定 | 行操作 | 锁定 Profile（仅未锁定时显示） |
| 解锁 | 行操作 | 解锁 Profile（仅锁定时显示） |

### ProfileFormDialog

**字段**：
- Profile Key（必填）
- 渠道（必填）
- 绑定任务（下拉，可选）
- 负责人（必填）
- 相对路径（必填）
- 备注

**按钮**：取消 / 保存 Profile

---

## 五、脚本库页 (`/scripts`)

### 统计卡片（2 个只读）
- 脚本总数
- 启用中

### 按钮

| 按钮 | 位置 | 动作 |
|------|------|------|
| 上传脚本 | 顶部 | 打开 ScriptUploadDialog |
| 详情 | 行操作 | 打开 ScriptDetailDialog |
| 停用 / 启用 | 行操作 | 切换脚本 enabled 状态 |

### ScriptUploadDialog

**字段**：
- 脚本名称
- 脚本编码
- 脚本类型（下拉：MAINTAIN / HEALTH / MANUAL / CUSTOM）
- 平台（下拉：COMMON / KUAISHOU / TAOBAO / TMALL / ALIMAMA / JD / PDD）
- 版本
- 说明
- 选择脚本文件（仅 `.py`）

**预览**：落盘目录 `runtime\scripts\uploaded\{code}\{version}`

**按钮**：取消 / 上传脚本

### ScriptDetailDialog

**展示内容**：
- 基础信息：名称、编码、类型/平台、版本、状态、更新时间
- 路径信息：脚本目录、绝对目录、主文件
- 说明

**按钮**：关闭

---

## 六、人工修复页 (`/repairs`)

### 统计卡片（3 个只读）
- 待处理工单
- 已打开浏览器
- 已关闭工单

### 按钮

| 按钮 | 位置 | 动作 |
|------|------|------|
| 刷新工单 | 顶部 | 重新加载工单数据 |
| 处理工单 | 行操作 | 打开 RepairGuideDialog |

### RepairGuideDialog

**展示内容**：
- 风险说明（风险类型、消息）
- 工单定位（工单号、任务名称、Profile Key、状态）
- 处理步骤指引（4 步文字说明）
- 执行记录（处理人、打开时间、关闭时间、产物目录）
- 处理人登记输入框

**条件按钮**（根据工单状态动态显示）：

| 按钮 | 显示条件 | 动作 |
|------|----------|------|
| 关闭 | 始终显示 | 关闭弹窗 |
| 打开修复浏览器 | OPEN / WAIT_RDP_REPAIR / FAILED | 锁定 Profile，拉起浏览器 |
| 我已完成，开始复检 | BROWSER_OPENED / VERIFYING | 解锁 Profile，执行健康检测 |
| 关闭工单 | 非 CLOSED | 弹出确认框 → 关闭工单（保留风险状态） |

- 检查项总数

- 失败项

### 按钮

| 按钮 | 动作 |

展示：检查项代码、状态（PASS / WARN / FAIL）、说明、记录时间

| 按钮 | 动作 |
|------|------|
| 刷新配置 | 重新加载部署配置 |

## 九、运行日志页 (`/logs`)

### 筛选器（8 个控件）

| 控件 | 类型 | 说明 |
|------|------|------|
| 运行类型 | 下拉框 | TASK / CHECK / REPAIR / SYSTEM |
| 状态 | 下拉框 | SUCCESS / PASS / FAIL / FAILED / RISK / WARN / BROWSER_OPENED / CLOSED |
| 任务 ID | 输入框 | 按任务 ID 筛选 |
| 检测 ID | 输入框 | 按检测 ID 筛选 |
| 工单 ID | 输入框 | 按工单 ID 筛选 |
| 关键字 | 输入框 | 搜索标题或消息 |
| 开始时间 | 输入框 | ISO 格式时间范围起始 |
| 结束时间 | 输入框 | ISO 格式时间范围结束 |

### 按钮

| 按钮 | 动作 |
|------|------|
| 筛选日志 | 按条件查询日志 |
| 重置 | 清空所有筛选条件 |
| 详情（行操作） | 打开 LogDetailDialog |

### LogDetailDialog

**展示内容**：
- 基础信息：运行 ID、类型、任务/检测/工单 ID、状态、时间
- 关联文件：日志文件路径
- 标题
- 消息全文

**按钮**：关闭

## 后端 API 模块清单

| API 模块 | 对应功能 |
|----------|----------|
| `dashboard` | 获取统计数据、最近日志、最近检测 |
| `session_tasks` | 任务 CRUD、启停切换、手动执行 |
| `health_checks` | 检测 CRUD、启停切换、单条/全部执行 |
| `profiles` | Profile 注册、锁定/解锁、复检 |
| `scripts` | 脚本上传、启停切换 |
| `repairs` | 工单查询、打开修复浏览器、复检、关闭工单 |
| `environment` | 执行环境自检、获取最近结果 |
| `deploy` | 获取部署配置（只读） |
| `logs` | 多条件筛选运行日志 |
